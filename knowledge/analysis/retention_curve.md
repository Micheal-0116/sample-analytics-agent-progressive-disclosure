# 分析方法 · 留存曲线 / Cohort (Retention)

> 套路：按"注册周期"分组(cohort)，看每组用户在第 N 天/周后还回来多少，画留存曲线/热力图。
> 留存是产品健康度的核心，比单看 DAU 更能反映粘性。

## 何时用
"留存怎么样""新用户第7天还在吗""哪批用户留得好""cohort 对比"等。

## ⚠️ 这份数据算不出留存 —— 先读这条，它决定结论怎么写

**这批种子数据的活跃度与注册生命周期是独立抽样的**，所以留存曲线**不衰减**。
实测（只取观测窗完整、≥5 周的 cohort，排除右删失干扰）：

```
第0周 45.0%   第1周 43.0%   第2周 42.1%   第3周 41.1%   第4周 43.0%
```

近乎水平，第 4 周还回升。**这不是"留存好、用户留得住"，这是数据没有建模用户生命周期。**
真实产品的留存必然前陡后平，D1 就该有明显断崖。

所以这道题的正确结论是：**给出数字 + 明说这份数据的留存结论不可用**，
把它写进 `risk` finding。**不要**把平坦曲线报成正面业务结论
（"曲线平稳、留得住""粘性好""忠实用户占比高"都属于这一类）。

反过来也不要过度纠正：**留存非单调是这份数据的真实性质，不是你的 SQL 错了**
（这一点和漏斗相反——漏斗非单调几乎总是口径错误，见 `funnel_analysis.md` 约束 A）。
两者的区别是：漏斗的单调性由 SQL 的子集约束保证，**留存的单调性由数据保证**，
而这份数据不提供它。

> 项目审计把「留存、流失、复购周期」整类列为**不可信**，原因就是这条。

## 统计公式（Cohort 留存，请照此算并填进 method）
设某 cohort 初始人数 N₀，第 t 天仍活跃人数 Nₜ：
- **第 t 天留存率**：Rₜ = Nₜ / N₀ —— 留存曲线纵轴。
- **常看点**：R₁（次日）、R₇（7日）、R₃₀（30日）。
- **区间流失率**：第 t→t+1 的流失 = (Nₜ − Nₜ₊₁) / Nₜ。
- **断崖点**：Rₜ 相邻两期跌幅最大的地方（通常在 D1，反映激活质量）。
> 曲线一般前陡后平；若长期趋于水平线，那条渐近线 ≈ 产品的"忠实用户占比"。

## 硬约束 · 分子必须限定在 cohort 成员内

Rₜ 的分子是「**这个 cohort 里**第 t 期还活跃的人数」，不是「第 t 期全站活跃人数」。
SQL 上就是活跃表必须 `JOIN` 上 cohort 成员名单（`ON act.user_id = coh.user_id`），
**不能只按时间筛活跃再除以 cohort 人数**。

漏掉这一步的后果很好认：**留存率会超过 100%**。实测过——分子取成全站活跃时，
第 1 周是 219 人 / cohort 43 人 = **509%**。所以**算完先看一眼有没有 >100% 的格子**，
有就是分子没限定住。（这和 `funnel_analysis.md` 的约束 A 是同一个毛病：
"没说清子集关系"。漏斗那次是悄悄给个像样的数，留存这次会直接炸出 500%。）

## 做法（这几步填进 present_result.method.steps）
1. **定义 cohort**：按 users.registered_at 的周(或日)分组。
2. **定义"回来"**：该用户在注册后第 N 天/周有 events 活跃（或有订单，看问题）。
3. 算每个 cohort 在第 0/1/7/14/30 天的留存率 Rₜ =
   **该 cohort 成员中**该期活跃数 / cohort 初始人数（见上面的硬约束；
   把 R₁/R₇/R₃₀ 填进 method.stats）。
4. 也可用 mart_user_summary 的 last_active_date 做粗略"是否近期活跃"判断。
5. 找规律写 `findings`：哪批 cohort 留得最好/最差、留存曲线在第几天断崖（跌幅最大处）。

## 输出要求
- chart 优先用 `heatmap`：xLabels=第N天/周, yLabels=各 cohort, cells=留存率。
  也可用 line 画几条代表性 cohort 的留存曲线对比。
- KPI：次日留存、7日留存、30日留存（整体）。
- insight 点出留存断崖位置和最佳/最差 cohort。
- 注意：近期注册的 cohort 还没到第30天，**留存窗口不完整不能和老 cohort 比**，放进 risk finding。
  热力图右下角那片 0 是**右删失**（观测窗未到），不是真实下跌，要说明。
- **但右删失这条不能替代顶部那条**：观测窗说明只解释了"边缘的 0"，
  没解释"中间那片为什么是平的"。两条都要写，只写前一条会让整段话听起来严谨、
  而结论仍然是错的。
